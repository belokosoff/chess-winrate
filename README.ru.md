Расширение для Chrome и Firefox (Manifest V3), которое показывает статистику игроков на chess.com.
Использует только публичный API chess.com и не подсказывает ходы. Неофициальное, не связано с Chess.com.

## Возможности

- Панель статистики на странице профиля (`/member/ник`), во время партии (для соперника) и на главной (для вашего ника из настроек).
- Вкладки: обзор, дебюты, концовки, «Когда», динамика, «Разбор», «Поражения», «Сравнение», личные встречи.
- Винрейт по цвету, дебютам, режимам, контролю времени (3+0, 10+0, …) и периоду; сильные и слабые дебюты.
- «Разбор»: расход времени, винрейт по рейтингу соперника, сессии (как вы играете после поражения), точность.
- «Динамика»: цель по рейтингу с прогнозом, неделя к неделе, графики рейтинга и скользящего винрейта.
- «Поражения»: последние 15 поражений со ссылкой на разбор партии на chess.com.
- Календарь партий во вкладке «Когда» и рейтинг задач в «Обзоре».
- «Сравнение»: два игрока рядом.
- Подсказка «сделайте перерыв» после 3 поражений подряд.
- Бейдж `WR xx%` рядом с никами, экспорт в CSV и JSON.
- Светлая и тёмная темы, перетаскиваемая панель (двойной клик по заголовку возвращает её на место), `Alt+W` сворачивает панель.
- Попап настроек: язык (русский, английский, испанский, немецкий, французский), тема, период и режим по умолчанию, глубина загрузки, ваш ник, цель, очистка кэша.

## Установка

**Chrome:** откройте `chrome://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите эту папку.

**Firefox:** откройте `about:debugging#/runtime/this-firefox`, нажмите «Загрузить временное дополнение…» и выберите `manifest.json`.
Временное дополнение пропадает после перезапуска Firefox; для постоянной установки его нужно подписать на addons.mozilla.org.

## Заметки

- Личные встречи считаются по вашим партиям. Укажите свой ник в попапе, иначе «мной» считается нижний игрок на доске.
- Партии хранятся в `storage.local` в сжатом виде. Прошлые месяцы кэшируются навсегда, текущий месяц обновляется раз в 5 минут.
- Селектор ников в партии (`[data-test-element="user-tagline-username"]`) зависит от вёрстки chess.com и может измениться.
- Точность есть только у партий, для которых вы открывали «Отчёт о партии» на chess.com.

## Публикация

```bash
node scripts/build.js
```

Создаёт `dist/winrate-stats-chrome-<версия>.zip` и `dist/winrate-stats-firefox-<версия>.zip`.
Пошаговая инструкция и тексты для магазинов: [store/listing.md](store/listing.md). Политика конфиденциальности: [PRIVACY.md](PRIVACY.md).

## Разработка

```bash
node test/test.js
```

`test/harness.html` рисует панель на реальных данных API без установки расширения. Запустите
`python3 -m http.server 8765` в корне проекта и откройте `http://127.0.0.1:8765/test/harness.html`
(параметры: `?user=ник&me=ник&lang=en&kind=profile&goal=450&theme=light`).
